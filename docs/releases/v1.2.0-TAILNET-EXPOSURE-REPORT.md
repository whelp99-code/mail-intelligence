# Mail Intelligence v1.2.0 Tailnet 포트 개방 보고서

- 수행일: `2026-08-30`
- 운영 서버: `jm-acloud`
- 애플리케이션 버전: `1.2.0`
- 운영 모드: `read-only`
- 공개 방식: Tailscale Tailnet 전용 TCP 프록시
- 접속 주소: `http://100.87.81.57:3010`
- 공인 인터넷 공개: 하지 않음

## 1. 목적

Node 애플리케이션의 loopback-only 안전 계약을 유지하면서 사용자의 Mac 등 같은 Tailnet에 가입된 장치에서 Mail Intelligence에 직접 접속할 수 있도록 `3010/tcp`를 연다.

## 2. 적용 구조

```text
Tailscale peer
  source: 100.64.0.0/10
        |
        v
100.87.81.57:3010
mail-intelligence-tailnet.service
        |
        v
127.0.0.1:3010
mail-intelligence.service
```

### 메인 서비스

```text
서비스: mail-intelligence.service
리스너: 127.0.0.1:3010
상태: active / running
```

### Tailnet 프록시

```text
서비스: mail-intelligence-tailnet.service
리스너: 100.87.81.57:3010
대상: 127.0.0.1:3010
허용 원본: 100.64.0.0/10
상태: active / running
```

프록시는 `0.0.0.0`에 바인딩하지 않는다. 바인딩 주소가 Tailscale CGNAT 범위 밖이거나 대상이 loopback 밖이면 시작을 거부한다.

## 3. 추가 구현

```text
src/security/tcp-allowlist-proxy.js
scripts/run-tailnet-proxy.mjs
scripts/activate-tailnet-proxy.sh
scripts/verify-tailnet-exposure.mjs
deploy/systemd/mail-intelligence-tailnet.service
test/tcp-allowlist-proxy.test.js
```

서버는 `MAIL_INTELLIGENCE_ALLOWED_PROXY_HOSTS`에 등록된 정확한 Tailnet IPv4 Host 헤더만 추가로 허용한다. 이 값도 `100.64.0.0/10` 밖이면 서버 시작 단계에서 거부한다.

## 4. 안전 경계

유지된 값:

```text
HOST=127.0.0.1
PORT=3010
MAIL_INTELLIGENCE_ACTIONS_APPROVED=0
MAIL_INTELLIGENCE_ALLOW_SEND=0
MAIL_INTELLIGENCE_ALLOW_MAIL_MUTATIONS=0
MAIL_INTELLIGENCE_ALLOW_DATA_PLANE=0
MAIL_INTELLIGENCE_ALLOW_EXTERNAL_AI=0
MAIL_INTELLIGENCE_ALLOWED_PROXY_HOSTS=100.87.81.57
```

권한:

```text
data/                                  0700
data/runtime.env                      0600
data/tailnet-proxy.env                0600
data/.mail-intelligence-access-key    0600
data/mail-intelligence.sqlite         0600
```

추가하지 않은 항목:

```text
0.0.0.0 애플리케이션 바인딩
Tailscale Funnel
공인 IP NAT
인터넷 공개 UFW 규칙
Mail.Send
Mail.ReadWrite
외부 행동 승인 플래그
```

Ubuntu의 UFW 설정 파일은 활성 상태로 확인되었으나, root 권한 방화벽 규칙을 변경하지 않았다. 포트 개방은 정확한 Tailscale 인터페이스 주소와 애플리케이션 레벨 원본 CIDR 제한으로 구현했다.

## 6. OAuth 주의

Tailnet 주소는 일상적인 읽기·검색·정밀 분류 UI 접속에 사용한다. 최초 Microsoft OAuth 로그인은 SSH 터널과 아래 loopback Redirect URI를 사용한다.

```text
http://127.0.0.1:3010/auth/callback
```

현재 실제 Outlook OAuth 자격정보는 설정되지 않았으므로 실제 회사 메일함 파일럿은 `NOT RUN`이다.

## 7. 운영 명령

```bash
cd /home/jm/orca/projects/mail-intelligence

export DBUS_SESSION_BUS_ADDRESS=unix:path=$XDG_RUNTIME_DIR/bus
systemctl --user disable --now mail-intelligence-tailnet.service
```
