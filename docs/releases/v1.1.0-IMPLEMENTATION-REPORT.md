## 1. 목적

v1.1.0의 목적은 메일을 매번 임시 JSON에서 다시 읽는 프로토타입을 끝내고, Outlook 전체 폴더의 메일·스레드·사람·수신자·첨부 메타데이터·사용자 보정·AI 분석을 SQLite에 누적하는 Persistent Mail Memory를 실제 런타임의 authoritative storage로 전환하는 것이다.

```text
Outlook folder discovery
→ page/delta collection
→ normalize
→ page transaction
→ SQLite persistent memory
→ search / correction / analysis cache
→ backup / restore / operational evidence
```

외부 행동은 v1.0.1과 동일하게 차단한다.

## 3. API

추가:

```text
GET  /api/storage/status
GET  /api/outlook/sync/status
POST /api/outlook/sync
GET  /api/mail/search
POST /api/storage/backup
```

복원 API는 제공하지 않는다. 복원은 다음 CLI에서만 가능하다.

```bash
node scripts/mail-memory-admin.mjs restore <backup> --confirm-stopped
```

## 4. 안전 경계

유지:

```text
Listen host: loopback only
Graph: Mail.Read only
Mail.Send: absent
Mail.ReadWrite: absent
Auto mark read: absent
Mail move/delete/category/flag: disabled
Calendar/task/CRM/Data Plane writes: disabled
```

DB 관리 API도 로컬 세션·Origin·CSRF 또는 보호 헤더를 요구한다. 복원은 HTTP로 노출하지 않는다.
