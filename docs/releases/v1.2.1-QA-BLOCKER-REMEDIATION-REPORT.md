## 1. 수정 요약

### F-01 Provider 상태 오판·오류 UX

다음 상태를 분리했다.

```text
CLI 설치
OAuth 로그인
최근 합성 모델 호출
최근 실메일 분석
운영 가능 상태
```

합성 테스트 및 실메일 분석 결과는 SQLite `audit_events`에 Provider별 최신 상태로 남는다.

오류는 다음 안전 코드로 변환한다.

```text
OAUTH_RELOGIN_REQUIRED
BILLING_BALANCE_EXHAUSTED
PROVIDER_TIMEOUT
PROVIDER_RATE_LIMITED
PROVIDER_TEMPORARILY_UNAVAILABLE
PROVIDER_INVALID_RESPONSE
PROVIDER_UNSAFE_TOOL_EVENT
PROVIDER_CALL_FAILED
```

402 오류는 결제·잔액 확인 안내로 변환하며 raw JSONL, CLI stderr, stack trace를 UI에 노출하지 않는다.

### F-02 Forwarded message 분리

현재 본문과 과거 전달·인용 본문을 분리한다.

지원 신호:

```text
Forwarded message
Forwarded Message
Begin forwarded message
Original Message
전달된 메시지 시작
보낸 메시지 시작
From/Sent/To/Subject 헤더 묶음
HTML blockquote
```

상태·행동 주체·우선순위·기한·보조 신호는 현재 본문만 사용한다. 전달된 과거 본문은 현재 행동으로 승격하지 않는다.

### F-03 Evidence exact span

Evidence는 다음 provenance를 가진다.

```text
sourceField
sourceMessageId
startOffset
endOffset
exactText
sourceHash
normalizationVersion
```

저장된 exactText는 canonical source의 해당 offset과 정확히 일치해야 한다. `(제목 없음)`은 UI placeholder로만 사용하며 Evidence·DB 원문에 저장하지 않는다.

### F-04 검색 Garbage

- Graph가 promotional로 식별한 메일은 자동 행동으로 승격하지 않는다.
- 뉴스레터·웨비나·광고·수신 거부 신호는 구체적 현재 업무가 없는 경우 Reference로 억제한다.
- 상업·보안·행동·기한 검색은 promotional 메일을 제외한다.
- 기한 검색은 Reference·Completed를 제외한다.
- 전달된 과거 본문의 기한은 현재 Due Date로 사용하지 않는다.
