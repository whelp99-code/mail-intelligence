Gateway `POST /mail/attachment-assets` binary proxy와 `POST /mail/drive/import` JSON proxy를 추가해 MI의 동일 suffix API로 전달한다. 기존 `/mail/drafts`는 MI `/api/mail/send-drafts`로 전달한다. binary는 2MiB bounded stream이며 JSON64KiB 제한을 변경하지 않는다. bot 사용자 입력은 서버 내부 draft bearer·Google 토큰을 덮어쓸 수 없다.

DETAIL: 명시 파일만 lstat/open하고 심볼릭 링크·디렉터리 거절 → 2MiB 누적 제한 → binary upload → 반환 asset ID로 draft 생성. HTTP JSON64KiB 한도는 그대로 둔다. 파일 bytes 로그 출력 금지. Drive는 MI에 ID import 요청만 하고 Google에 직접 로그인하지 않는다. idempotency 키는 호출 단위로 고정하여 네트워크 재개 시 동일 payload에만 재사용한다. draft 생성은 가능하지만 승인·cancel·다운로드는 bot403 테스트로 보장한다. 중간 실패 시 초안에서 누락시키지 말고 전체 요청 실패와 이미 생성한 자산 ID만 보고한다.
