## 사용자 흐름과 화면 상세

1. 작성 화면: 본문 아래 `PC 파일 첨부`, `Google Drive에서 선택`, `Drive 링크 추가` 세 동작을 분리한다. 링크와 실제 첨부를 같은 아이콘으로 표시하지 않는다.
2. 파일 행: 이름, 정확한 bytes와 표시 크기, 출처, 변환 형식, 검사 진행/성공/실패, 제거 버튼. 서버 ready 이전에는 초안 저장을 막는다. 실패 파일을 조용히 제외하지 않는다.
3. 승인 화면: 수신인·본문과 파일 목록을 함께 표시한다. 파일 다운로드 후 검토할 수 있다. 승인 체크박스에 “수신인, 본문, 첨부파일/링크를 확인했습니다”를 명시한다. 다운로드는 attachment 응답이며 브라우저 내 실행 미리보기는 제공하지 않는다.
4. Drive 링크 행: “파일 첨부가 아닌 링크이며 수신자의 접근 권한은 확인되지 않았습니다”를 표시한다. 공유 권한 자동 변경 버튼은 범위 밖이다.
5. 발송 상태: 발송 요청 접수와 확인된 발송을 구분한다. 불확실 상태에는 재발송 버튼을 제공하지 않고 읽기 전용 대사 동작만 제공한다.
6. 오류는 한국어로 표시하고 요청 추적 ID를 함께 제공한다. 키보드 탭 이동·레이블·aria-live 진행 상태·모바일 가로 넘침을 검증한다. 파일명은 textContent로 표시한다.

## 성능 목표와 측정법

초기 목표: 로컬 합성 2MiB 파일 20회 업로드에서 p95 5초 이내(검사 포함), 두 요청 동시 실행 시 서버 RSS 증가 64MiB 이하. Drive는 외부 지연을 별도 기록하며 다운로드/변환 제한시간 30초, 검사 15초, 승인 전 재확인 10초를 적용한다. 목표 미달이면 실제 값·환경을 보고하고 한도를 늘리거나 검사를 생략하지 않는다. 전체 Graph 발송 timeout은 기존 정책을 유지한다.
