# Mail Intelligence v1.2.2 — Operational Classification Stabilization

## 0. 결정

qa-fix9의 의미 사건·상태 머신 개선은 적용하되 `qa-fix9`라는 임시 릴리스 이름을 만들지 않는다.

정식 제품 버전은 다음으로 고정한다.

```text
package                         1.2.2
classifier                      precision-classification-v1.2.2-fix9
mail event frame                mail-event-frame-v3
operational projection          operational-classification-v1.2.2
search                          intelligent-search-v1.2.2
release                         Operational Classification Stabilization
```

v1.2.2의 목적은 모든 메일을 억지로 자동 확정하는 것이 아니다.

> 확실한 업무는 빠르게 배치하고, 불확실하거나 충돌하는 메일은 절대 조용히 보관하지 않으며, 사람이 확인한 보정을 이후 판단에 축적한다.

## 2. 내부 상태와 운영 Lane

기존 6개 상태는 API·DB 호환성을 위해 유지한다.

```text
action_required
waiting
decision_required
completed
reference
review_required
```

사용자 화면과 일상 운영은 다음 4개 Lane으로 단순화한다.

```text
DO_NOW
WAITING
REVIEW
ARCHIVE
```

기본 매핑:

| 운영 Lane | 내부 상태 |
|---|---|
| `DO_NOW` | `action_required`, `decision_required` |
| `WAITING` | `waiting` |
| `REVIEW` | `review_required`, 충돌, 낮은 신뢰도, Archive 차단 |
| `ARCHIVE` | 높은 신뢰도의 `completed`, `reference`만 |

## 3. qa-fix9 의미 사건·상태 머신

정규식은 최종 상태를 직접 확정하지 않고 사건 후보를 추출하는 Detector로만 사용한다.

```text
메일 원문
→ 현재 본문 / 인용·전달 / Footer·Disclaimer 분리
→ direction·folder·draft·automation 판정
→ 사건 후보 추출
→ 사건 family·actor·target·tense·request·commitment·completion 판정
→ 상태 머신 reconciliation
→ Work State / Next Actor
→ Priority
→ Operational Lane / Archive Guard
```

사건 family:

```text
user_action
external_commitment
internal_commitment
decision
completion
business_document
meeting
incident_security
automated_reference
ambiguous
```

핵심 precedence:

1. 현재 본문의 직접 행동·결정 요청은 과거 완료 문장보다 우선한다.
2. 상대방의 미래 작업·회신 약속은 `WAITING / EXTERNAL_PARTY`다.
3. 내가 보낸 행동 요청은 `WAITING / EXTERNAL_PARTY`다.
4. 내가 전달만 완료하고 후속 요청이 없으면 `COMPLETED / NONE`이다.
5. Support 종료 승인 질문은 완료가 아니라 `ACTION_REQUIRED / ME`다.
6. Support 해결 통보이고 후속 요청이 없으면 `COMPLETED / NONE`이다.
7. 신규 문서 도착은 처리 의무가 명확하지 않으면 `REVIEW_REQUIRED`다.
8. 광고·뉴스레터·일반 인증번호·단순 영수증은 `REFERENCE`다.
9. 충돌을 해소할 수 없으면 `REVIEW_REQUIRED`로 fail closed 한다.

## 4. Silent Action Miss 방지 계약

다음 신호가 하나라도 있으면 자동 `ARCHIVE`를 금지한다.

```text
현재 직접 요청 후보
현재 결정 질문
상대방 미래 작업·회신 약속
현재 기한·긴급 근거
meeting intent
incident/security
신규 업무 문서
첨부파일 확인 필요
사건 후보 간 상태 충돌
낮은 Work State 또는 Actor 신뢰도
Rules와 선택적 Luna 불일치
```

Archive는 다음을 모두 만족할 때만 허용한다.

```text
state ∈ {completed, reference}
Work State confidence >= 0.90
Actor confidence >= 0.90 또는 nextActor=none
상태 충돌 없음
silent-risk signal 없음
Evidence 검증 PASS
사용자 보정과 충돌 없음
```

## 5. 선택적 Luna adjudication

Luna는 전체 Mailbox를 재분류하거나 단독 정답을 만드는 모델이 아니다.

호출 후보:

```text
REVIEW Lane
사건 후보 충돌
Next Actor unknown
Support lifecycle ambiguous
Business document ambiguous
Incident/Security ambiguous
```

전송 최소 범위:

```text
제목
현재 본문 currentContent
발신/수신 방향
폴더 유형
수신 시각
첨부 메타데이터 이름·형식·크기
```

제외:

```text
과거 인용 전문
다른 메일 원문
첨부 전체 내용의 자동 전송
Mailbox 전체
Credential·Secret
```

외부 AI 정책 OFF일 때:

```text
Rules 결과 유지
불확실 결과는 REVIEW
서비스 중단 없음
다른 Provider 자동 fallback 없음
```

Rules와 Luna가 합의하면 candidate confidence를 높일 수 있지만, 불일치하면 REVIEW를 유지한다.

## 8. 첨부파일 요약 범위

v1.2.2에서 Attachment Summary는 안전한 후보 기능으로 제공한다.

```text
TXT     저장·전달된 추출 텍스트 요약 가능
PDF     추출 텍스트가 제공된 경우 요약 가능
DOCX    추출 텍스트가 제공된 경우 요약 가능
```

현재 Graph 동기화가 첨부 메타데이터만 저장하는 경우에는 임의로 본문을 만들지 않는다.

```text
contentAvailable=false
summaryStatus=metadata_only
nextAction=원문을 Outlook에서 확인하거나 승인된 추출 경로 사용
```

첨부 요약은 메일 Work State를 자동 확정하지 않는다. Attachment evidence가 검증되고 사용자가 승인한 경우에만 향후 지식 후보로 사용할 수 있다.

## 9. 미팅 후보

현재 본문에서 미팅 의도와 시간 표현을 추출한다.

```text
meetingIntent=true
candidateTimes=[]
timeZone=Asia/Seoul 또는 원문 명시 timezone
availability=unknown | available | conflict
calendarWriteAllowed=false
confirmationDraftAllowed=true
```

Calendar 연결이 없으면 availability를 추측하지 않고 `unknown`으로 둔다.

## 10. 완료 기준

### 운영 위험 Gate

```text
Silent Action Miss              <=2%
False Action                    <=2%
Critical/High False Positive    0
Uncertain Mail Review Coverage  100%
Evidence Exact                  100%
Search direct relevance         >=90%
User Correction Persistence     PASS
External automatic action       0
```

### 회귀 Gate

```text
Outlook Delta twice             PASS
SQLite integrity                PASS
Backup/restore                  PASS
Restart persistence             PASS
Tailnet/auth                    PASS
Provider OFF fallback           PASS
```

6-state exact accuracy는 계속 측정한다. 그러나 `ACTION_REQUIRED → REVIEW`와 `ACTION_REQUIRED → ARCHIVE`를 같은 위험으로 취급하지 않는다. 정식 운영에서 가장 먼저 막을 것은 Silent Action Miss다.
